วิธีใช้บน Render
1) อัปโหลดโฟลเดอร์นี้ (package.json + server.js) ขึ้น GitHub
2) Render > New > Web Service > เลือก repo
   Build Command: npm install
   Start Command: npm start
3) Environment Variables
   GEMINI_API_KEY = คีย์จาก Google AI Studio
   SHARED_SECRET  = รหัสลับที่คุณตั้งเอง
4) เปิด https://ชื่อแอป.onrender.com/ ต้องเห็นคำว่า ok
